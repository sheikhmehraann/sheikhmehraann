## 👨‍💻 Executive Summary

I am a security researcher and low-level Android engineer specializing in **ARM64 kernel space**, **MediaTek EL3 bootchain vulnerabilities (LK / Preloader)**, **hardware-level security state spoofing**, and **AOSP / XOS 15 ROM architecture**.

My work focuses on breaking and securing the post-Preloader boot chain, developing native kernel-level VFS root concealment techniques, and creating cross-platform reverse engineering tools.
