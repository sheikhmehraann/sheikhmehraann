### 📋 Overview

I am a **Systems Engineer & Low-Level Security Researcher** specializing in hardware security policies, exception level forensics (**EL3**), OS kernel internals, and native high-performance software development.

My primary research centers around reverse engineering ARM64 bootloaders, evaluating security policy restrictions on MediaTek Dimensity chipsets, and engineering low-overhead Windows memory optimization engines.

---

### 🔬 Research & Engineering Focus

* **Bootchain & Hardware Security:** Exploiting MediaTek `bl2_ext` security policy bypasses, hardware lock state spoofing (`LKS_LOCK`), and enforcing `ro.boot.verifiedbootstate=green` for Strong Play Integrity.
* **Systems Programming:** Native C/C++ and C# (.NET Core) Windows system software development using Win32 / NT Native APIs, memory management, and AOSP vendor image unpacking.
* **Vulnerability Analysis:** Firmware reverse engineering (Ghidra, IDA Pro), binary disassembling, and LLM safety guardrail vulnerability stress-testing.
