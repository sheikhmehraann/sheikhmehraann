### 🛠️ Executive Summary

Systems software engineer and security researcher specializing in ARM64 architecture, bootchain security policies, exception level forensics (EL3), and OS kernel internals. 

Lead maintainer of **[Fenrir](https://github.com/sheikhmehraann/fenrir)**, an open-source security exploit and hardware patching framework for MediaTek Dimensity bootchains (`X6861`, `X6871`, `mt6878`, `mt6895`), enabling verified boot state spoofing (`ro.boot.verifiedbootstate=green`) and lock state spoofing (`LKS_LOCK`) for Strong Play Integrity.

---

### 🔬 Core Specializations

* **ARM64 Bootchain Security:** `bl2_ext` security policy bypasses, hardware lock state spoofing, EL3 exception level diagnostics, and AVB VBMeta verification flag manipulation.
* **Systems & Kernel Tooling:** High-performance Win32 native memory optimization (C# / C++), dynamic partition rebuilding, vendor image unpacking, and custom Android bootloader engineering.
* **Vulnerability & AI Security Research:** Binary reverse engineering (Ghidra, IDA Pro), LLM safety guardrail evaluation, and automated vulnerability analysis.
